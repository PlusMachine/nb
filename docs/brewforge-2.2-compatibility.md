# BrewForge 2.2: совместимое обновление экрана управления

Изменение согласовано владельцем 22 октября 2026 года. `schema` остаётся 1,
все прежние поля и команды сохранены. Форматы NVS и разделы flash не меняются.

Необязательные поля телеметрии:

- `pendingHop: {index, name, amountG, count}` — одно текущее внесение, ожидающее подтверждения, с исходным индексом для `ACK_HOP`. `index=-1`, пустое имя и `count=0` означают отсутствие события. События фильтруются по текущему кипячению/хопстенду.
- `outputs: [{role, label, on}]` — подключённые и используемые выходы; роль одна из `heater1`, `heater2`, `pump1`, `pump2`, `valve`, `cooler`. Пустой массив — отображать нечего. При отсутствии поля сайт использует прежний вид.

`nextHopName` и `nextHopG` сохраняют прежний смысл будущего ещё не сработавшего внесения. Их нельзя использовать как имя текущего алёрта. Для старых прошивок без `pendingHop` при алёрте сайт предлагает уточнить внесение на экране устройства, не отправляя подтверждение по догадке.

Сайт принимает старую прошивку; старые клиенты могут игнорировать новые поля.
Для полного исправления напоминаний нужны и новая прошивка, и обновлённый сайт.
