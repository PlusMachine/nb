# Проверка исправлений быстродействия NB

Проверяется production-сборка с изолированной копией данных. Исходный аудит: ../performance-audit-2026-11-04/README.md.

| Пункт | Функциональная проверка | Визуальное состояние и измерение |
| --- | --- | --- |
| A1 | Главная HTTP 200, оба превью этикеток валидны; отказ рендера сохраняет главную | Главная 390/1440, заголовок и основные действия |
| A2 | Миниатюры рецептов используют оптимизированные публичные изображения; фото рецепта доступно с прежними правами | Desktop/mobile, DPR 1/2, объём ресурсов и время загрузки на ограниченной сети |
| A3 | Текст виден до загрузки шрифтов, переключение оформления сохраняется | Холодный профиль CLS для каталога/калькулятора/редактора, светлая/тёмная тема |
| A4 | Меню открывается первым нажатием до гидратации, затем закрывается, ссылка/Escape/клик вне работают | Замедленная сеть + CPU, открытое меню при загрузке и после неё |
| A5 | Степперы кипячения доступны; обратная связь по-прежнему открывается в редакторе | 360/390/834, начальный экран и прокрутка, диалог обратной связи |
| A6 | Поиск, очистка во время/после запроса, повторное посещение, быстрый ввод, Back и внешние фильтры | Пустое поле соответствует URL/списку, ожидание завершается |
| A7 | Счётчики и параметры читаемы | Контраст Lighthouse/axe, активные и неактивные категории |
| A8 | Новый рецепт начинает работу с параметров и состава; показатели доступны после добавления и при явном раскрытии | Первый ингредиент 360/390/834, пустой и заполненный рецепт |
| Регрессия | Создать рецепт, добавить ингредиент, сохранить и открыть заново; отказ POST и повтор | Статус и значения сохраняются, клавиатура/диалоги/темы |
| Исследовательский проход | Переходы редактор → склад → поиск → очистка → покупки → партии | 30–90 секунд обычного ввода и прокрутки |

Отказные сценарии: ошибка генерации превью, медленный/прерванный поисковый запрос, обрыв сохранения рецепта. Лабораторные результаты не являются полевым p75/INP.

Финальный результат: A1–A8 проверены. Подробные результаты и ограничения — в [отчёте](README.md).
