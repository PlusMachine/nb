# План и покрытие мобильного аудита

21.10.2026. Текущее рабочее дерево. Проверки старых аудитов не засчитываются как новые.

Размеры: 320×740, 360×800, 390×844, 768×1024, 834×1112, 1024×768; дополнительно 844×390 для открытых диалогов. Chromium touch, доступные WebKit/Firefox отдельно.

| Область | Функциональная проверка | Визуальные состояния |
|---|---|---|
| Оболочка | Меню, переходы, поиск, профиль, тема, обратная связь | Меню открыто, выбранный пункт, нижняя панель, длинный экран |
| Публичные разделы | Главная, BrewForge, демо, статьи, BJCP, мастера, рынок, legal | Первый экран, длинный контент, карточки и таблицы |
| Каталог/рецепты | Поиск, фильтры, выбор/сброс, карточка, списки, меню | Открытые dropdown, пустой поиск, длинные названия |
| Редактор рецепта | Новый рецепт, ингредиенты, стиль, оборудование, вода, импорт/экспорт | Заполненный редактор, picker, popover, ошибки ввода |
| Склад/покупки | Добавление, изменение, фильтры, диалоги, пустое состояние | Формы, строки, кнопки и клавиатурный фокус |
| Оборудование | Создание, пресеты, редактирование, отмена | Полная форма, селекты, диалог |
| Варки | Список, детали плана/процесса/завершения, меню | Полосы статуса, таблицы, графики, диалоги |
| Устройства | Список, добавление, демо, настройки | Управление, графики, подключение |
| Калькуляторы | Все доступные страницы, ввод, единицы, вкладки, сброс | Результаты, открытые списки, подсказки |
| Этикетки | Шаблоны, настройки, предпросмотр, скачивание | Мобильный редактор и предпросмотр |
| Аккаунт | Вход, профиль, настройки, кабинет мастера | Формы, валидация, onboarding |
| Админка | Списки, фильтры, формы без изменения чужих данных | Таблицы, горизонтальная прокрутка, действия |

Исследовательские сценарии: узкий экран с длинным текстом; поворот с открытым меню; пустой/некорректный ввод; повторное открытие и отмена диалога; поиск без результатов; возврат после выбора.

Для каждого прохода сохраняются URL, размеры, HTTP/JS ошибки, размеры документа и подозрительных элементов, снимки. Метрики переполнения сами по себе не подтверждают визуальное качество.
