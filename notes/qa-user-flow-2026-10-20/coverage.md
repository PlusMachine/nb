# План проверки пользовательского пути, 20.10.2026

Проверяем актуальное рабочее дерево без изменения продуктового кода.

| Этап | Сценарии | Ожидаемое подтверждение |
|---|---|---|
| Первый вход | Новый обычный аккаунт, пустой склад, подсказки следующего шага | UI и скриншот |
| Склад | Каталог, свой ингредиент, единицы, дробные количества, ноль, редактирование | Сохранённый остаток после обновления |
| Оборудование | Первый профиль, объём, эффективность, потери, профиль по умолчанию | Сохранённый профиль и применение |
| Поиск рецепта | Пустой и наполненный склад, точные совпадения, аналоги, нехватка | Список и расшифровка соответствия |
| Масштабирование | Уменьшение/увеличение, перенос в свой рецепт, оборудование | Объёмы и количества до/после |
| Партия | Создание, повторная варка, параметры, склад | Видимая партия и её состав |
| Варка | Шаги, таймер, фактические значения, обновление страницы | Сохранённый прогресс |
| Склад партии | Недостаток, замены, списание, повторное списание | Остатки и статус без двойного расхода |
| Завершение | Брожение, измерения, розлив, завершение, отмена | Корректные переходы и история |
| Мобильный интерфейс | 390px и 360px, модалки, формы, карточка партии | Скриншоты и метрики переполнения |

Не заявляем исчерпывающую проверку всех сочетаний. В отчёте отделяем пройденные UI-сценарии от проверок по коду и непроверенных веток.
