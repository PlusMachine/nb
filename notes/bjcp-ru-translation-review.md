# Ревью русского перевода описаний стилей BJCP (/bjcp)

Дата: 2026-07-17. **Статус: ✅ все находки исправлены в тот же день** (глоссарные сквозные замены + P0-диапазоны + кириллизация name_ru по решению владельца + нормализация tags_ru; тесты @nb/content зелёные, живая /bjcp проверена). Ниже — исходный отчёт ревью.

Проверены все 20 файлов `ingredients/bjcp/bjcp_styles_ru_detailed_part_*.json` (~128 стилей + подтипы 21B) и `bjcp_style_families_ru_v2.json`. Каждая секция `sections_ru` сверялась с английским оригиналом `sections_en`. Проверяли 7 независимых агентов-критиков, по пачке файлов на каждого.

## Вердикт

**Общая оценка: 7–7.5/10.** Это НЕ нейрослоп и не сырой автоперевод: синтаксис живой, канцелярита и «который»-нагромождений почти нет, базовое терминоядро (сусло, засыпь, затирание, карбонизация, эфиры, фенолы, диацетил, финиш, тело, питкость, отварка, краузенинг) корректное и стабильное, ё последовательная, кавычки почти везде «ёлочки». Но текст переводился явно несколькими заходами без единого глоссария: есть 3–4 системные терминологические ошибки, прокатившиеся через весь корпус, рунглиш-вкрапления в секциях ингредиентов, разнобой названий/тегов между файлами и десяток точечных искажений судейских спецификаций. Нужен один сквозной редакторский проход по глоссарию + точечные смысловые фиксы.

## Системные проблемы (по всему корпусу)

### С1. crisp → «хрусткий/хрустящий/хрустче» — главный дефект, ~25+ вхождений
Пиво не хрустит. Встречается везде: 1A, 1B, 1C, 1D, 2A, 2C, 4A, 4B, 5B, 5D, 12B, 19B, 23A, 23B, 23E, 25C, 26A, 27 (Grodziskie ×2, Pre-Pro Lager ×2 — включая аграмматичное «хрустче»), 28A, 28D, 29D, X5. Замена по контексту: «сухой», «резкий», «освежающий», «чёткий». «Crisp acidity» = «резкая/освежающая кислотность».

### С2. Ложные друзья переводчика
- **palate → «палитра»** (25A, 9C, 24B, Kentucky Common, Lichtenhainer): palate = вкус/ощущение во рту.
- **tart → «терпкий»** (23B, 23F, 23G, Lichtenhainer): tart = кислый/кисловатый; терпкость (astringency) — другой дескриптор.
- **characterful yeast → «характерные дрожжи»** (11A, 11B, 11C): правильно «выразительные» (как в 13A).
- **marmalade → «мармелад»** (17D): это апельсиновый джем, не русский мармелад.
- **house ale/house character → «домашний»** (18A, 23D): правильно «фирменный/базовый сорт заведения».
- **carbonic bite → «углекислотный укус»** (1A, 1B, 2A, 16D «колючий укус»): «покалывание углекислоты».

### С3. Выдуманные слова (точечный нейрослоп)
«эльовый» (13A, 18B, X4, X5 — при этом «эльные» в 22C/24A и «элевые» в 5B/7B — три формы одного слова!), «вкусонасыщенный», «белосортовый», «питьебельность» (34B, рядом же есть «питкость»), «подтостованный» (33A/33B), «минералистый», «хмелегорький», «специалитетный», «лёгкотелый», «газовитость», «сухохмелевой», «мальтовый» (23C), «лагеризированное», «пинтовое пиво», «гравитационный класс».

### С4. Рунглиш — английские слова посреди русских фраз
Хуже всего в `characteristic_ingredients`: «adjuncts» (то латиницей, то «адъюнкты»), «crystal malt»/«character malt» (рядом же «карамельные солода»), «dry hopping / dry hop / dry-hop’ят / сухохмелевой» — 4 формы при принятом «сухое охмеление», «off-dry», «mouthfeel», «sipping-пиво», «скорее sipping, чем drinking», «session-strength крепостью», «historically» (11C — прямой сбой конвейера), «rustic», «provision ale», «sour mash», «medium-low», «amyloglucosidase», «Sherry/Port/Madeira» (в 17D переведено — непоследовательно).

### С5. Искажения судейских спецификаций (для BJCP это смысловые ошибки)
Уровни/диапазоны интенсивности сдвинуты или выдуманы:
- 15B flavor: «Moderate roasted» → «от умеренного до выраженного» (диапазон выдуман) — P0
- 21B-White IPA aroma: «Moderate esters» → «от умеренных до высоких» — P0
- X3 mouthfeel: «Medium-high carbonation» → «от средней до высокой» — P0
- 20A mouthfeel: «should not be strong» → «не должна быть заметной» (запрещает разрешённое) — P0
- 4C aroma: low → «умеренные»; 7B aroma: moderate → «умеренно слабый»; 20A aroma: high → «довольно заметный»; 13B: heavy caramel → «довольно заметный»; 11B: decidedly bitter → «горьковатый»; 19A: запрет жареных тонов ослаблен «выраженно»
- 23A style_comparison: порог Brett инвертирован («below threshold» → «почти пороговый»)
- 11C style_comparison: сравнение подменено (special → ordinary)
- 7B comments: «served from casks» → дописаны кеги
- X2 flavor: выдуман «розовый» грейпфрут
- 4B history: «more poundable» → «пригодный для больших кружек» (искажение)
- 34A: «посекундного копирования» — бессмыслица; 32B comments: дописана фраза, которой нет в оригинале
- Пропуски: 12B «lingering bitterness», 12C хвост про два типа IPA, 18B «less intensely hop-focused and bitter», 21B шуточные примеры (Romulan Blue IPA и др.), 27-Kellerbier «higher production»

### С6. Разнобой между файлами (переводились разными заходами)
- **Названия стилей — три схемы одновременно**: «Ирландский stout» / «Сладкий стаут» / «Уи-хеви»; «Шотландский light/heavy/export» при полностью русском 14A в файле семейств; «Оуд браун» (правильно «Оуд брюин»); «барли вайн» раздельно (принято «барливайн»); «Блонд эль» без дефиса при «пейл-эль»; «Дорада пампеана» vs «Дорада Пампеана» (part_19 vs families).
- **roast/toast/burnt — хаос**: «жареный/обжаренный/обжарённый (орфогр. ошибка ×4)/поджаренный/жжёный/тост/подтостованный» без системы; в 2C из-за этого потеряно различие burnt vs roasted, в 16D aroma «burnt» стал «поджаренным».
- **tags_ru нестабильны** (ломает будущую фильтрацию): «высокая/повышенная крепость», «поджаренный/обжаренный», «семейство wheat beer»/«семейство пшеничного пива», «семейство bock»/«семейство боков», род тегов скачет.
- Мелочи: off-white пена — 5 вариантов; toffee — «тоффи/ирис»; «кристальные/кристаллические/crystal»; «горче/горше»; род Guinness скачет; «Сухой закон» с разной капитализацией; Michael Jackson то латиницей, то кириллицей; десятичная точка vs запятая; дефис vs тире в диапазонах; точечные “лапки” вместо «ёлочек» (part_20, 9B, Grodziskie).

### С7. Прочее заметное
- «декокционное затирание» (Roggenbier, 23A) — принято «отварочное».
- «визуально» вместо «по ощущению» для seem/impression (X4, 21B-Belgian, 25B) — сухость не видна глазами.
- «тестовый» вместо «тестяной» для doughy (4B, 4C) — омоним с test.
- 19B: температуры только в °F; 5B: «20 cl».
- 3C: в vital_statistics потерян abv + мусорный хвост колонтитула PDF «6 BJCP Beer Style Guidelines - 2021 Edition» в тексте.
- Sahti в tags «Центральная Европа» (баг исходных данных BJCP, слепо перенесён).
- 26A: «горький и хмелевой бельгийский столовое пиво» — сломан род на весь абзац.
- «с сдержанной» вместо «со сдержанной» (8A, 13C ×2); «во финише» (9A); «светло-бежёвая» (17A); «не скучным» раздельно (5A).

## Рекомендуемый порядок фиксов
1. **Глоссарий + сквозные замены**: crisp, tart, palate, roast/toast/burnt-ряд, «эльные/элевые», dry hopping → «сухое охмеление», adjuncts → «несоложёные добавки», carbonic bite. Это закрывает ~70% находок.
2. **P0-список из С5** — точечная сверка диапазонов интенсивности с оригиналом (это судейский документ, уровни = контент).
3. **Единая схема name_ru** (решение владельца: транслит vs латиница) + нормализация tags_ru.
4. Орфография/пунктуация: «обжарённый», «со/с», кавычки, тире, °C.
