## P0 — кислоты (water.ts:401–417, water-plan.ts:624–654)

- [x] **Ф1. Промывка = титрование карбонатной системы, а не «линейный буфер».**
  `acidMeq = alkMeq × (f1(pH_цели) − f1(pH_источника))`, где f1 — доля нейтрализованной щёлочности (по deLange, pKa1 6,38): при цели 5,7 нейтрализуется ~82%, при 5,5 ~88%. Убрать члены `литры×2`, `щёлочность×2` и floor 20 мЭкв/pH.
  Щёлочность брать из **промывочного** bucket-профиля с солями (сейчас `sourceProfile.hco3`, water-plan.ts:648–650 — сода в промывке не учитывается).
  Приёмка: 14 л/172 ppm/5,7 → 3,3±0,3 мл; осмос → ≤0,4 мл.
- [x] **Ф2. Затор = mEq-метод закрытой формулой (вместо бинпоиска по фиктивному буферу).**
  `acidMeq = B×кг×max(0, pH_засыпи_DI − pH_цели) + Ct×(f2(pH_предсказ) − f2(pH_цели))`, где B ≈ 40 мЭкв/(кг·pH) (диапазон 34–60 по Riffe/deLange — вынести в константу с комментом), Ct — карбонаты затворной воды. Солодовый буфер титруется от DI pH засыпи, а НЕ от RA-сдвинутого предсказания (сейчас щёлочность считается дважды: в raShift и в буфере ×2).
  Приёмка: кейс Москвы → 9,5–11 мл.
- [x] **Ф3. Предупреждение о вкусовом пороге лактата.** Если суммарная молочная кислота даёт >~400 ppm лактата на объём партии — варнинг + подсказка «фосфорная кислота или разбавление осмосом». (Московскую воду с щёлочностью 172 даже честной дозой молочной не спасти.)

## P1 — модель pH затора (water.ts:332–388, water-plan.ts:314–339, 606–618)

- [x] **Ф4. Убрать `mineralAdjustment`** (water.ts:362): двойной разнонаправленный учёт Ca/Mg (RA уже учитывает их по Кольбаху), а floor −0,06 портит дистиллят (5,64 вместо 5,7–5,85).
- [x] **Ф5. Взвешенный DI pH засыпи вместо линейных поправок** (Riffe Eq.4): `pH_засыпи = Σ(pHi·Bi·fi)/Σ(Bi·fi)`; pHi: светлая база 5,75–5,85, мюних/венский ~5,5–5,6, карамель 4,6–5,3 (по цвету), жжёные 4,64±0,13, кислый солод — как сейчас (−0,1/1%). Выкинуть мёртвую константу `plato = Math.max(1, 12)` (water.ts:354) вместе с colorShift.
- [x] **Ф6. Классификатор солодов** (water-plan.ts:314–339): сейчас только EN-ключи по отображаемому имени — «Chocolat» (без 'e'), «жжёный», «карамельный», «кислый солод» уходят в base; «cara» ловит **Carafa** (жжёный!) в карамель. Фиксы: проверять roasted-ключи первыми (carafa|роаст|жжён|чёрн|black|roast|chocolat), добавить RU-ключи; правильное решение — прокидывать класс из каталожной таксономии (subtype сейчас несёт только malt|fermentable).

## Источники верификации

- A.J. deLange, «Acidification of Water» (HBD #2388) — формулы титрования карбонатов, доза ~2,1 мл/10 л при 150 ppm.
- D.M. Riffe & M. Spencer, «A Homebrewing Perspective on Mash pH III» (2018) — pHi/Bi солодов: база ~5,85/40–60, жжёные 4,64±0,13/~69, карамель 4,63–5,34.
- braukaiser.com — порог лактата ~400 ppm (эксперимент), буферы солода (сырые ~30–35, ×1,62 к шкале deLange).
- Bru'n Water / Brewer's Friend — практика подкисления промывки (цель pH <6, финальная щёлочность <50 ppm).
