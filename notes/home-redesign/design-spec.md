# ТЗ для дизайнера — главная страница `/`

Референс: `mockup.html` в этой папке (интерактивный; кнопка «Пометки дизайнера» внизу справа
показывает обоснование каждого блока). Макет — направление, не пиксель-перфект: финальные
отступы/размеры сверять с живыми страницами витрины (`/recipes`, `/bjcp`).

## 1. Визуальный язык

Существующая дизайн-система, ничего нового не изобретаем:

- **Фон страницы** `#f4f4f6`; карточки — белые, `border zinc-200`, радиусы 18–24 px,
  hero и пульт — крупный радиус (32–40 px). Тени — мягкие, как на текущем hero.
- **Шрифты**: display — Montserrat (600/700/800), body — Rubik (уже подключены через `next/font`).
  Все цифры — `tabular-nums`.
- **Нейтрали**: текст `zinc-950`, вторичный `zinc-600`, приглушённый `zinc-400`.
- **Акцент** — SRM-палитра цвета пива (`features/recipes/beer-color.ts`) как сквозная
  акцентная система + amber-600 для ссылок/рейтинга (уже так на витрине).
- **Единственный тёмный блок** — пульт BrewForge (`#141417`, карточка телеметрии `#1d1d22`).
  Вся «смелость» страницы потрачена здесь; остальные блоки спокойные. Второй тёмный блок не заводить.
- Тема — только светлая (как весь продукт).

## 2. Поблочная спецификация

### 2.1 Hero + витальная панель
- Сетка 2 колонки (~55/45), на мобиле — столбец, панель под текстом.
- Слева: eyebrow «Домашнее пивоварение», H1 «Свари своё пиво — от рецепта до розлива»
  (остаётся), саб-строка, CTA «Собрать рецепт» (тёмная) + «Смотреть рецепты» (ghost).
- Справа — витальная панель стиля: стакан (существующий `BeerGlassIcon`, ~86×120,
  градиентная заливка по SRM), рядом код BJCP + название стиля + словесное название цвета
  из палитры («Светло-золотистый» и т.п.).
- Под ними 4 стат-ячейки: OG (°P), IBU, ABV (%), Цвет (EBC) — диапазоны из BJCP 2021.
- Ниже — 6 чипов стилей с цветной точкой, отсортированы **от светлого к тёмному**:
  Хеллес · Чешский пилснер · Вайсбир · Американский IPA · Дункельвайцен · Ирландский стаут.
  Активный чип — инвертирован (тёмный фон). Состояние — `aria-pressed`.
- Переход при переключении: цвет стакана перетекает ~0.5 s (`ease-out-expo`),
  цифры — быстрый кросс-фейд (~0.25 s). Без подпрыгиваний и лишнего motion.
- Подпись-источник внизу панели: «Диапазоны — из справочника стилей BJCP» (ссылка на `/bjcp`).

### 2.2 Чипы семейств стилей
*(Ревизия 2026-07-03: заменяет «Цветовую полосу» — поиск рецепта по цвету не входной
паттерн; по стилю — входной. Те же семейства, что табы фильтра `/recipes`.)*
- Заголовок секции «Рецепты сообщества», справа ссылка «Все рецепты».
- Ряд чипов-пилюль: название семейства (nameRu из каталога BJCP) + число рецептов
  мелким приглушённым. Порядок — `sortOrder` каталога, пустые семейства скрыты
  (как в фильтре витрины).
- Каждый чип — ссылка `/recipes?family=<id>`.
- Мобайл: перенос строк (`flex-wrap`), без горизонтального скролла.

### 2.3 Карточки рецептов
- Ровно существующий `RecipeCard` с витрины — **без адаптаций** (обложка по SRM, чип стиля,
  рейтинг, 4 параметра, автор, объём). 3 штуки в ряд, на мобиле в столбец.

### 2.4 Петля мастерской
- Заголовок «Как работает мастерская», справа ссылка «Начать».
- 4 фрейма с номерами 1–4 (номер = информация, это реальная последовательность):
  **Склад** — две строки ингредиентов с остатком и полосой запаса;
  **Рецепт** — мини-стат-панель (OG · IBU · EBC) + строка «Стиль 21A — попадание ✓» (зелёный);
  **Варка** — «Кипячение · 60 мин» с прогрессом + таймер-строка «Через 12:30 — внести Citra, 30 г»;
  **Журнал** — партия/день брожения, замер плотности, «списание склада — выполнено».
- Фрагменты стилизованы под настоящий UI (фон `#fafafa`, тонкая рамка), под каждым —
  одна строка мелкого текста-факта (это факт о механике, не рекламный слоган).
- Мобайл: горизонтальный свайп со scroll-snap, ширина фрейма ~78 vw.

### 2.5 BrewForge (пульт)
- Тёмная секция, 2 колонки: слева eyebrow «BrewForge», заголовок
  «Варочный день — с помощником или на автомате», два режима списком
  (Помощник / Автомат — название + одна строка сути), CTA «Как устроена автоматика» (amber).
- Справа — панель телеметрии: заголовок «Затирание · пауза 2 из 3», пилюля «связь»
  (зелёная точка, пульс; отключается при `prefers-reduced-motion`), крупная цифра факта
  (66,8 °C) + «цель 67,0 °C · осталось 18 мин», строка «Дальше: осахаривание 72 °C → кипячение 60 мин»,
  график температуры (одна линия amber, пунктир цели, тихая сетка, подписи осей 10–10.5 px).
- График — иллюстрация формата данных контроллера, не живой; рисовать честный профиль
  затирания (паузы-полки, подъёмы), не абстрактную кривую.

## 3. Копирайтинг

Финальные тексты — в `mockup.html`, они согласованы с глоссарием продукта. Правила:

- Термины как в живой речи пивоваров: засыпь, затирание, паузы, осахаривание, охмеление,
  сухое охмеление, карбонизация, аттенюация видимая, сусло, об.%, °P, EBC, IBU, OG/FG.
- Никаких калек и выдуманных переводов (не «хмелестояние», не «живой режим»).
- Никаких пояснительных подзаголовков под кнопками: если элемент нельзя понять без пояснения —
  чинить сам элемент.
- Никаких «мощный», «удобный», «интуитивный» — только проверяемые факты и цифры.

## 4. Чего не делать

- Стоковые фото (пена, бородатые пивовары, медные чаны) — весь визуал строится из
  SRM-палитры и фрагментов UI.
- Второй тёмный блок, градиентные hero-подложки, эмодзи в заголовках.
- Карусели/автослайдеры — всё скроллится руками.
- Анимации ради анимаций: разрешены только переход цвета стакана, кросс-фейд цифр,
  hover-подъёмы и пульс «связи» (с уважением к `prefers-reduced-motion`).
