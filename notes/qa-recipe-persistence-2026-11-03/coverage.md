# Сохранение рецептов, численные границы и права

3 ноября 2026 года, время Москвы. Отдельная QA-база Docker PostgreSQL и реальные пользовательские сессии. Первичные результаты сохранены отдельно; таблица показывает повторную проверку исправлений.

| ID | Проверка | Результат |
|---|---|---|
| P01 | Правки во время медленного сохранения | passed: после B сохранено последнее C |
| P02 | Сетевой отказ обновления и повтор | passed: ввод остаётся, повтор сохраняет изменения |
| P03 | Потерянный ответ создания рецепта | passed после B07: одна запись после повтора, новые правки сохранены, reload восстанавливает рецепт |
| P04 | Перезагрузка после сохранения | passed: подтверждённое состояние восстановлено |
| P05 | Две вкладки меняют разные поля | passed после B06: конфликт виден, локальный ввод и сохранённые данные целы |
| P06 | Общая дата меняется без изменения содержимого (фото/агрегаты) | passed: ложного конфликта нет, реальная ревизия редактора остаётся защищённой |
| N01 | Нулевой/отрицательный объём и неверное кипячение | passed после B03: отказ без изменения записи |
| N02 | NaN, Infinity и переполнение | passed после B03/B04: отказ без изменения записи |
| N03 | Малый положительный объём | passed после B04: отклонён, не превращается в ноль |
| N04 | Неверные единицы объёма | passed: сервис отклоняет |
| N05 | Миллиграммы и переход мг/г/кг на складе | passed: 40 мг остаются 0,04 г |
| N06 | Невместимая точность массы | passed: явный отказ |
| N07 | Повторные идентификаторы строк | passed после B05: отказ без потери строк |
| N08 | Масса рецепта 40 мг в кг и смена единиц | passed после B04: 0,00004 кг = 0,04 г при сохранении |
| A01 | Чужой приватный рецепт | passed: отказ сервиса и закрытый UI второго аккаунта |
| A02 | Изменение/удаление чужого рецепта | passed: отказ, исходник цел |
| A03 | Чужой склад | passed на сервисном уровне: изменение отклонено |
| A04 | Чужая партия и оборудование | passed на сервисном уровне: доступ/изменение отклонены |
| A05 | Захваченный Server Action под чужой сессией | passed: запрос второго пользователя отклонён |
| A06 | Личные заметки публичного рецепта | passed: отсутствуют в публичном DTO |

Доказательства: [первичный проход БД](db-exploration.json), [первичный проход UI](ui-exploration.json), [регрессионные проверки](tools/all-targeted-integration.log). Исторические failed в исходных JSON не переписываются. Сервисная проверка не означает, что пройден соответствующий UI.
