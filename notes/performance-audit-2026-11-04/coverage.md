# План проверки скорости и удобства

Дата: 4 ноября 2026, Europe/Moscow. Проверяется текущий рабочий каталог с существующими незакоммиченными изменениями. Исходники приложения не меняются.

| Область | Проверка поведения | Проверка вида и доказательство |
| --- | --- | --- |
| Первое посещение | Загрузка главной, каталога, рецептов, BJCP, калькуляторов; cold/warm; TTFB, FCP, LCP, CLS, long tasks, размеры ресурсов | Первый экран desktop 1440×900 и mobile 390×844; замедленная сеть и CPU; JSON метрик и снимки |
| Поиск и навигация | Каталог и BJCP: ввод, быстрый повторный ввод, пустая выдача, сброс, переход к карточке, Back | Ввод не теряет фокус, результат соответствует последнему запросу, видимое ожидание и результат |
| Калькуляторы | Открытие, изменение параметров, вычисление результата, переключения | Результат виден и читаем на desktop/mobile; отклик при вводе |
| Личный кабинет | Открытие dashboard, склада, рецептов и партий с настоящей сессией в копии базы | Навигация, содержательные пустые/заполненные состояния, плотность интерфейса |
| Редактор рецепта | Создать отдельный QA-рецепт, изменить параметры и ингредиент, дождаться сохранения, открыть заново | Доступность основных действий, статус сохранения, поведение на узком экране, время ввода/сохранения |
| Склад | Поиск, фильтры, открытие добавления, выбор ингредиента и возврат | Диалоги, фокус, размеры сенсорных целей и читаемость |
| Оболочка | Меню, тема, клавиатура, возврат в исходное состояние | 360×800, 390×844, 834×1112, 1440×900; горизонтальный скролл/перекрытия |
| Отказной сценарий 1 | Быстрый ввод и запрос без результатов | Нет устаревшей выдачи и неоднозначного состояния |
| Отказной сценарий 2 | Обрыв/ошибка поискового запроса либо offline-переход | Ясное состояние и возможность повтора |
| Исследовательский проход | 30–90 секунд обычных переходов, прокрутки и изменений | Записать найденные дополнительные состояния, не выдавать выборку за полный аудит всех функций |

Каждая итоговая находка требует воспроизводимого сценария и привязки к снимку, метрикам или исходнику. Лабораторные замеры не равны полевому INP/p75. Непроверенные области будут явно указаны.

## Результат прохода

| Область | Итог |
| --- | --- |
| Главная | Не проходит: A1, HTTP 500 и ошибка SVG; нормальное содержимое главной не оценено |
| Холодная загрузка | Каталог, калькулятор, редактор: по три прогона; остальные основные страницы по одному. A2–A4 подтверждены |
| Тёплая загрузка | Каталог: повторная загрузка; 90 запросов HTML к 18 маршрутам без ошибок; ёмкость сервера под нагрузкой не заявляется |
| Каталог | Поиск, быстрый повторный ввод, пустая выдача, сброс, карточка и Back; фокус и запрос сохраняются |
| BJCP | Поиск 21A, карточка, Back с сохранением запроса, открытие фильтров и Escape |
| Калькулятор | Изменение OG, видимый результат, переключение шкал и возврат, сброс |
| Личный кабинет | Обзор, рецепты, склад, покупки и партии; оборудование и приборы только HTML smoke |

| Склад | Поиск и очистка: A6, неустойчивый результат; фильтры открываются/закрываются; подбор в добавлении выдаёт результаты; изменение остатков не проверялось |
| Оболочка | Мобильное меню и Escape; тёмная тема и возврат к системной; обратная связь: A5, реальное нажатие перехвачено |
| Визуальная проверка | Просмотрены исходное и изменённое состояния, диалоги, светлая/тёмная тема. Редактор 360/390/834 и desktop 1440; горизонтальный скролл не найден; A5 и A7 остаются |
| Исследовательский проход | Переход редактор → склад, повтор поиска и очистки, модалки, покупки и партии; выявлен A6 |

Все восемь пунктов имеют доказательства в README. Проверка всего приложения, всех калькуляторов, реальных iOS/Android и аппаратных команд не заявляется. Оценка удобства A8 отделена от функциональных ошибок.
